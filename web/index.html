문서형 + 3회차

원본 사진과 정규 품종명·외형 설명을 짝지은 Google 문서를 소스로 쓰세요. 이번 문서형 3회차는 사진 퀴즈의 핵심 조건에 가장 가까웠습니다.

  • 앞면 사진 10/10장
  • 화면·대체텍스트 정답 노출 0장
  • 명칭 오류 0장 · 외형 특징 2개 조건 충족

미해결: 노르웨이 숲·메인쿤 사진 잘림이 관찰됐습니다. 완전 성공으로 보지는 않습니다.

이미지형 3회차에는 자세를 품종 특징처럼 설명한 사례가 남았습니다. 더 엄격하고 긴 프롬프트가 항상 더 낫지는 않았습니다.

슬라이드형 사진 퀴즈

1회차는 전체 슬라이드로 정답이 노출됐고, 2회차는 사진이 사라졌으며, 3회차는 사진이 뒷면으로 이동하고 12장이 생성됐습니다.

앞면에서 사진을 보고 맞히는 퀴즈라면 슬라이드를 기본값으로 선택하지 마세요.

  4. 생성 후 검수: 10장을 모두 뒤집어 사진 위치·정답 노출·설명·잘림을 확인한 뒤 학습자에게 공유합니다.
문서형에 권장 · 실제 실험 원문

복사해서 쓸 3회차 프롬프트

추천 문서형 노트북 열기 ↗

복사 버튼을 사용할 수 없으면 아래 원문을 직접 선택해 복사하세요. 고양이 10품종 실험에 사용한 원문 그대로입니다. 다른 주제에 맞춰 품종·대상·개수를 바꾸면 수정본이므로 다시 검수해야 합니다.

[3회차 테스트: 사진 퀴즈 전용] 세트 이름 “3회차 | 정답 비노출 사진 퀴즈”. 원본 자료 안의 실제 고양이 사진으로만 10개의 한국어 품종 맞히기 카드를 완성하세요. 대상 정규 명칭은 페르시안 / 메인쿤 / 샴 / 래그돌 / 벵갈 / 브리티시 쇼트헤어 / 러시안 블루 / 아비시니안 / 노르웨이 숲 / 스핑크스이며 한 품종 한 장입니다. 카드 앞면에 학습자가 볼 수 있는 것은 고양이 사진 한 장과 동일한 질문 “이 고양이의 품종은 무엇일까요?”뿐이어야 합니다. 소스가 문서·슬라이드라도 페이지 캡처가 아니라 글자가 없는 사진 자체를 사용하세요. 사진 영역 바깥 제목·라벨·출처를 제외하되 고양이의 귀·발·꼬리는 보존하고 이미지 전체를 비율 유지로 맞추세요. 품종명은 앞면 본문, 이미지 안의 글씨, 대체텍스트, 접근성 이름, 툴팁 어디에도 노출하지 마세요. 대체텍스트는 “품종을 맞힐 고양이 사진”으로 통일하세요. 원본 외 이미지나 생성 그림은 금지합니다. 뒷면은 정규 품종명과 관찰 가능한 외형 특징 2개를 짧은 일반 문장으로 쓰세요. 글머리·번호·표는 쓰지 마세요. 소스에 없는 특징을 보태거나 자세를 품종의 고유 특징으로 단정하지 마세요. 완성 전 10품종 중복/누락, 사진-정답 불일치, 한글 명칭 오타, 정답 누출, 사진 잘림을 점검하고 발견한 오류를 바로잡은 결과만 제시하세요. 실제로 할 수 없는 이미지 처리에는 성공했다고 쓰지 말고 제한을 밝혀 주세요.
사진 파일만 쓸 때: 이미지형 + 2회차 원문

이미지형의 2회차 결과를 근거로 한 대안입니다. 문서형의 우위나 2회차의 일반적 우수성을 통계적으로 입증한 것은 아닙니다.

[2회차 테스트] 제목은 “2회차 | 고양이 원본사진 플래시카드”로 해 주세요. 한국어 카드 정확히 10개, 다음 품종을 각각 1회만: 페르시안, 메인쿤, 샴, 래그돌, 벵갈, 브리티시 쇼트헤어, 러시안 블루, 아비시니안, 노르웨이 숲, 스핑크스. 현재 선택된 소스의 실제 고양이 사진만 사용하세요. 문서나 슬라이드는 사진 영역만 추출하고 페이지·슬라이드 전체, 제목, 품종명, 설명, 출처 문구를 앞면 이미지에 넣지 마세요. 새 그림을 생성하거나 외부 사진으로 대체하지 마세요. 사진은 가로세로 비율을 유지해 전체가 보이게 배치하고 귀·꼬리·발을 자르지 마세요. 앞면은 사진과 “이 고양이의 품종은 무엇일까요?”만. 이미지 대체텍스트/접근성 이름도 정답을 숨겨 “고양이 사진 1”처럼 중립적으로 지정하세요. 뒷면은 번호나 글머리 목록 없이 3줄: “품종: [정규 품종명]”, “특징 1: [형태 특징]”, “특징 2: [다른 형태 특징]”. 품종명은 위 표기를 그대로 쓰세요. 자세·촬영배경·주관적 수식어를 품종 특징으로 쓰지 마세요. 래그돌의 흰 무늬처럼 유형에 따라 다른 특징을 모든 개체의 특징으로 단정하지 마세요. 사진과 정답을 원본 파일명·설명에 맞춰 대조하세요. 원본 사진 추출/배치를 할 수 없다면 해냈다고 주장하지 말고 제한을 명시하세요.
2회차 실제 결과 보기 ↗

이 프롬프트를 써도, 이것은 직접 확인하세요

  • 정확히 10장이고 품종 중복·누락이 없는가?
  • 사진이 앞면에 실제로 보이며 원본 사진과 정답이 대응하는가?
  • 앞면 글자·이미지 속 글씨·대체텍스트에 정답이 새지 않는가?
  • 뒷면의 두 특징이 자료에 근거하고, 자세·배경·특정 개체 무늬를 품종 전체의 특징으로 단정하지 않는가?
  • 귀·발·꼬리가 잘리지 않고 이름과 설명을 끝까지 읽을 수 있는가?

잘림이 남으면: 프롬프트가 해결했다고 믿지 마세요. 다시 생성해도 문제가 남고 사진 전체 보존이 필수라면, 직접 사진 배치를 조절할 수 있는 도구로 마무리하세요. 기존 Notebook 카드의 특정 문항을 직접 편집·저장하는 기능은 이번 UI에서 확인되지 않았습니다.

추천 범위: 동일한 고양이 사진 10장·단일 계정·3회 관찰에 근거한 실무적 선택입니다. 문서형이나 3회차 프롬프트가 모든 주제에서 항상 최고라는 뜻이 아니며, 새 프롬프트를 추가 생성해 검증한 결과도 아닙니다.

동일한 고양이 사진 10장, 이미지 10개·슬라이드 1개·문서 1개로 소스 분리. 매 회차 세 노트북에 같은 프롬프트와 한국어·표준·보통·이미지 포함 설정 적용.

  • 실제 카드 수와 품종 누락·중복
  • 원본 사진 재사용과 사진-품종 대응
  • 앞면 정답 노출과 대체텍스트 정답 노출
  • 명칭·설명 정확성 및 지시 준수
  • 사진 크롭·텍스트 잘림·직접 편집 가능성

무엇을 말할 수 없나

  • 1개 계정·1개 주제의 3회 사례 연구이며 일반적 성능이나 통계적 인과관계를 보장하지 않습니다.
  • 품종 대응은 업로드 설명을 기준으로 한 육안 비교입니다. 사진 해시 동일성이나 실제 혈통을 감정하지 않았습니다.
  • 실제 생성 모델 버전·토큰·비용·정확한 생성 소요시간은 측정하지 않았습니다.
  • 캡처 도구 오류는 제품 오류와 분리했고 미검수 부분은 재확인해 보충했습니다.
  • 표시·도구 정책은 관찰일 이후 달라질 수 있습니다.
  • 사진 수는 앞면·뒷면을 구분합니다. 3회차 슬라이드형 뒷면 이미지 11장에는 고양이 사진 10장과 일반 안내 슬라이드 1장이 포함됩니다.
